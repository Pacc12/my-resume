# Interactive Digital Resume

A professional, responsive, and secure digital resume designed with a minimalist UI. This project serves as a bridge between Business Administration principles and Computer Science implementation.

## Live Demo
[View the live resume here](https://pacc12.github.io/my-resume/)

## Key Features
- Responsive Design: The layout is fluid and adapts to desktop, tablet, and mobile screens using CSS Media Queries.
- Secure Contact Proxy: Utilizes an integrated Google Form with response validation and manual verification to protect personal contact information from automated scripts.
- Interactive Integration: Includes live Google Maps links for educational institutions and work history to provide immediate verification of professional background.
- Visual Interface: Implements modern CSS techniques, including glass-morphism and custom grid layouts, to create a high-end user experience.

## Technical Stack
- Frontend: HTML5, CSS3 (Grid, Flexbox, Media Queries)
- Deployment: GitHub Pages for version control and hosting.
- Backend Integration: Google Forms for data collection and security.

## Project Purpose
This project was developed to demonstrate proficiency in front-end web development while maintaining a focus on professional data privacy and user experience. It highlights the ability to deploy a live, functional product using industry-standard tools.
